# Changelog

Semua perubahan penting pada Memonopoli : Wilayah WNI dicatat di sini.

## [0.3.2-beta] - 2026-11-16

### UI dalam permainan
- Tombol toolbar atas kini berlabel (**Cepat, Kamera, Pasar, Menu, Nego**), bukan hanya ikon. Di HP label disembunyikan agar tetap satu baris.
- Kartu pemain menampilkan **"🏠 N wilayah · 💎 kekayaan"** yang lebih jelas; ikon status (🛡️ 🎒 🏝️ ✈️) dikelompokkan sendiri.
- Panel **Catatan** default ringkas (hanya kejadian terakhir) supaya tidak menutupi papan; klik "▸ riwayat" untuk daftar lengkap.
- Dialog **Beli/Bangun** menampilkan sewa dan **sisa uang setelah beli**; harga tidak lagi terpotong ganti baris.
- HP: notifikasi tidak lagi menimpa toolbar, tombol "LEMPAR DADU" tetap satu baris.

### Negosiasi, Pasar & Jual Aset
- Dialog yang memakai peta mini kini memakai tata letak **split**: peta di kiri dan daftar di kanan pada layar lebar, peta menempel di atas pada HP. Peta tetap terlihat walau asetnya banyak.
- Tombol **Kirim/Batal** beserta ringkasan selisih nilai selalu terlihat di bawah dialog.
- Negosiasi: badge **"N dipilih"** di tiap kolom.
- Jual aset: kotak **Harus bayar / Uangmu / Kurang** tetap terlihat saat menggulir; daftar dikelompokkan (Turunkan bangunan / Jual ke bank / Cara lain) dengan strip warna grup.
- Daftar pajang wilayah di Pasar diberi strip warna grup.
